# Veille et agenda · Vivre Mieux

Plateforme de veille et d'agenda pour les élu·es du groupe Vivre Mieux (Toulouse),
publiée sur agenda.vivremieuxtoulouse.fr (hébergement o2switch).

- `site/` : la plateforme (dossier public du sous-domaine).
- `site/api.php` : lit la feuille Google (événements, actus, quartiers) et enregistre les présences.

Aucune donnée n'est stockée dans ce dépôt : la feuille Google est privée,
et les réglages comme les présences sont sur le serveur, dans `~/agenda-data/`, hors du dossier public.
